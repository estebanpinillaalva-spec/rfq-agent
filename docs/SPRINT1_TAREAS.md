## 🛑 BLOQUEOS CONOCIDOS Y CÓMO RESOLVERLOS

### Si GitHub Student Pack tarda en aprobar
**Acción:** No te bloquea. Sigue con todo lo demás. Cuando llegue, instalas Copilot gratis.

### Si Sales Navigator pide datos de pago
**Acción:** Activa la prueba gratuita con tarjeta + recordatorio para cancelar 28 días después. Si no quieres tarjeta: usa LinkedIn normal (más limitado pero usable).

### Si /execute-plan genera código con errores que no entiendes
**Acción:** /review primero. Si no resuelve: copia el error literal y pregunta a Claude Code "explícame este error y propón solución".

### Si nadie acepta tus invitaciones LinkedIn
**Acción:** Revisa tu perfil personal: foto profesional, descripción clara, mención al proyecto. La aceptación viene del perfil, no del mensaje.

### Si te sientes abrumado a mitad de semana
**Acción:** Para. Revisa GSD. Marca lo MÁS importante. Solo eso. Las tareas atrasadas se redistribuyen, no se hacen 14h en sábado.
