# RFQ Agent Piloto Local

Piloto CLI local para procesar una carpeta con `email.txt`, planos y `config-taller.json`.

Por defecto funciona en modo `mock` sin coste ni claves externas. Para pruebas reales con IA multimodal, configura `RFQ_AI_PROVIDER=gemini` y `GOOGLE_GEMINI_API_KEY` en `.env.local`.
